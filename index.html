Features

键盘优先，信息密度高，响应迅速Keyboard-first, dense, and fast

为高频远程操作设计：少一次抬手去摸鼠标，少一屏无用留白。 Built for high-frequency remote work: one less reach for the mouse, one less screen of empty space.

VT 终端引擎VT terminal engine

自绘渲染的终端控件，DEC ANSI / VT / Xterm 状态机与十种终端 profile。256 色与 24 位真彩、CJK 双宽、线绘字符、鼠标协议，OSC 8 超链接与 OSC 133 命令块一个不落。 A self-drawn terminal control with a DEC ANSI / VT / Xterm state machine and ten terminal profiles. 256 colours and 24-bit truecolor, CJK double width, line drawing, mouse protocols, OSC 8 hyperlinks and OSC 133 command blocks.

SSH / SFTP / FTP 与本地终端SSH / SFTP / FTP and local shells

与本机终端（Windows ConPTY）同屏并列；断线自动重连，睡眠唤醒与网络恢复也照顾到。Side by side with local shells (Windows ConPTY); automatic reconnect, even after sleep or a network drop.

认证与密钥Auth and keys

密码、私钥、SSH 证书与 Agent；两步验证、主机指纹 TOFU，共享凭据改一处全生效。Passwords, keys, SSH certificates and Agent; two-step auth, host-key TOFU, and shared credentials updated in one place.

跳板机与代理Jump hosts and proxies

原生 ProxyJump 链式跳转（≤5 跳、环检测），HTTP / SOCKS5 / 跟随系统代理。Native chained ProxyJump (up to 5 hops, loop detection), plus HTTP / SOCKS5 / system proxies.

内置 X 服务端Built-in X server

VelaShell.XServer：每个 X 窗口一个原生窗口，剪贴板双向、多显示器与 DPI、GLX 1.4。VelaShell.XServer: a native window per X window, two-way clipboard, multi-monitor and DPI aware, GLX 1.4.

SFTP 双栏与目录同步Dual-pane SFTP and sync

拖拽互传、断点续传与传输队列；目录比较按 SHA-256，远程文件内置编辑器改完即回传。Drag-and-drop, resumable transfers and a queue; SHA-256 directory sync; edit remote files and save straight back.

端口转发隧道Port-forwarding tunnels

本地 -L / 远程 -R / 动态 SOCKS5 -D，实时连接数与字节数，端口冲突预检。Local -L, remote -R and dynamic SOCKS5 -D, with live counters and port-conflict checks.

VelaDock 工作区The VelaDock workspace

零第三方停靠依赖的拖拽分屏，多终端同步输入，命令面板直达全部动作；快捷键可改键、可解绑，还能从 Xshell / WinSCP / ~/.ssh/config 导入会话。 Drag-to-split docking with no third-party dock dependency, synchronized input across terminals and a command palette for every action; rebindable shortcuts, and session import from Xshell / WinSCP / ~/.ssh/config.

运维工具箱Ops toolbox

资源监视、进程管理、带地理信息的路由追踪；会话录制可导出 asciicast v2。Resource monitor, process manager, geo-aware traceroute; session recording exportable as asciicast v2.

数据与安全Data and security

凭据 AES-256-GCM 加密；GitHub Gist 云同步可端到端加密、版本可回溯；安全审计日志。Credentials encrypted with AES-256-GCM; optional end-to-end encrypted Gist sync with history; a security audit log.

12 套主题12 themes

7 暗 5 亮，与 16 套终端配色成对联动，全令牌化、零硬编码颜色。7 dark and 5 light, paired with 16 terminal palettes — fully tokenized, no hard-coded colours.

双模插件系统 + AI 助手Dual-mode plugins + AI assistant

插件进程内或独立进程装载，危险能力逐项授权，.vpx 打包与发布者指纹钉住。第一方 AI 助手随程序发布：读懂会话上下文，Agent 模式下执行只读命令并总结，支持 MCP。Plugins load in-process or isolated, with per-capability consent, .vpx packages and pinned publisher fingerprints. The first-party AI assistant ships with the app: it reads the session context, runs read-only commands in Agent mode and supports MCP.

堡垒机 / SSO 拉起Launched by bastions / SSO

按 Xshell 的调用约定被外部拉起，换客户端不必改门户。Uses Xshell's calling convention — swap the client without touching the portal.

Plugins

一条命令建工程，一条命令发出去One command to scaffold, one to ship

插件工程只引用一个 NuGet 包，契约程序集、与宿主一致的 Avalonia、清单校验与打包器都随它到位。 A plugin project references a single NuGet package — the contract assembly, a host-matched Avalonia, manifest validation and the packer all come with it.

~/plugins
# 装模板，建工程，打出 .vpxinstall the templates, scaffold, produce a .vpx
$ dotnet new install VelaShell.Plugin.Templates
$ dotnet new velaplugin-ui -n MyPlugin --publisher acme
$ dotnet build -t:PackVpx
 
# 从插件商店装别人的插件install someone else's plugin from the marketplace
$ dotnet tool install -g VelaShell.Plugin.Cli
$ vela-plugin install velashell.redis
